# Web Development

> Modern frontend engineering, backend architecture, REST/GraphQL APIs, and full-stack development.

---

## 1. Overview

This directory covers modern full-stack web development principles, ranging from foundational web standards (HTML5, CSS3, ESNext) to modern component-driven frontend frameworks and robust backend services.

---

## 2. Topics Covered

### Frontend Engineering
- **Core Web Technologies**: Semantic HTML5, modern CSS (Flexbox, Grid, Custom Properties), and vanilla JavaScript (DOM, Events, Async/Await)
- **TypeScript**: Static typing, interfaces, generics, and compiler configurations
- **React Ecosystem**: Component architecture, Hooks, State Management (Context, Zustand, Redux Toolkit), and performance optimizations
- **Next.js & SSR**: Server-side rendering, static site generation, API routes, and App Router architecture

### Backend Engineering
- **Node.js & Express / Fastify**: HTTP server architecture, middleware, routing, error handling, and authentication (JWT, OAuth2)
- **Databases & ORMs**:
  - Relational: PostgreSQL, MySQL with Prisma / Drizzle / TypeORM
  - Non-Relational: MongoDB, Redis for caching and session management
- **API Design**: RESTful API standards, OpenAPI / Swagger specifications, and GraphQL

## 4. Documentation & Best Practices

- Always decouple business logic from presentation components.
- Enforce strict typing with TypeScript across full-stack applications.
- Document API contracts and provide sample request/response payloads.
