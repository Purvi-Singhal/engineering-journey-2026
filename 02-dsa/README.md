# Data Structures & Algorithms (DSA)

> Algorithmic problem solving, standard data structure implementations, and computational complexity analysis.

---

## 1. Overview

This directory tracks problem-solving practice, algorithmic patterns, and custom data structure implementations. The primary objective is to develop pattern-recognition skills and write clean, optimal, and edge-case-resilient solutions.

---

## 2. Topics & Patterns

- **Complexity Analysis**: Big-O notation for time and space complexity
- **Linear Data Structures**: Arrays, Dynamic Arrays, Linked Lists, Stacks, Queues, Deques
- **Non-Linear Data Structures**: Trees (Binary, BST, AVL, Trie, Heap), Graphs (Adjacency List/Matrix)
- **Algorithmic Patterns**:
  - Two Pointers & Fast/Slow Pointers
  - Sliding Window
  - Binary Search
  - Prefix Sums & Hashing
  - Breadth-First Search (BFS) & Depth-First Search (DFS)
  - Backtracking & Recursion
  - Dynamic Programming (1D, 2D, Knapsack, Longest Common Subsequence)
  - Greedy Algorithms & Interval Scheduling
  - Graph Algorithms (Dijkstra, Topological Sort, Disjoint Set Union / Union-Find)

---

---

## 4. Problem Solution Standards

Each problem solution should include:
1. **Problem Statement & Constraints**: Brief context and edge conditions.
2. **Intuition & Approach**: Thought process and algorithmic choice.
3. **Complexity**: Explicit Big-O Time and Space complexities.
4. **Clean Code**: Well-commented, readable code with edge case handling.
