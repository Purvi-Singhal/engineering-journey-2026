# Weekly Reviews & Accountability Logs

> Consistent tracking of weekly progress, completed goals, technical roadblocks, and upcoming commitments.

---

## 1. Overview

Sustainable engineering mastery relies on consistent iteration and deliberate practice. This directory houses weekly review logs to track learning streaks, evaluate what was built, diagnose blockers, and establish actionable goals for the following week.

---

## 2. Weekly Review Template

Each weekly entry should follow this markdown template:

```markdown
# Weekly Review: Week [Number] ([Start Date] - [End Date])

## 1. Key Accomplishments
- [Track / Area]: Summary of what was learned or implemented with links to code/notes.
- [Track / Area]: Problem solutions completed.

## 2. Code & Artifacts Created
- Link to relevant commits, PRs, or problem solution files.

## 3. Roadblocks & Learnings
- **Challenge**: Difficult concept, debugging issue, or time constraint encountered.
- **Solution / Resolution**: How it was resolved or what research remains.

## 4. Next Week's Commitments
- [ ] Primary Goal 1: ...
- [ ] Primary Goal 2: ...
- [ ] Primary Goal 3: ...
```
