---

## 2. Project Standards

Every project added to this directory must adhere to the following baseline:

1. **Dedicated Project README**:
   - High-level architecture overview and system diagram
   - Problem statement and core value proposition
   - Tech stack and architectural trade-offs
   - Step-by-step local setup and environment configuration
   - API documentation or UI walkthrough
2. **Clean Code & Architecture**:
   - Clear separation of concerns (presentation, business logic, data access)
   - Consistent naming conventions and modular design
3. **Automated Testing**:
   - Unit tests covering critical domain logic
   - Integration tests for API endpoints or workflows
4. **Reproducibility**:
   - Dockerized setup or locked dependency specifications (`package-lock.json`, `poetry.lock`, Gradle wrapper)
   - `.env.example` file documenting required environment variables
5. **No Committed Secrets**:
   - Strict adherence to secret management practices.
